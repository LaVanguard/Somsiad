### 5. **CSRF Security Hardening** ✅ **CRITICAL FIX**

**Problem:**
All API endpoints used `@csrf_exempt` decorator, bypassing CSRF protection - major security vulnerability

**Solution:**

**1. Removed `@csrf_exempt` from all endpoints:**
- `knowledge/document_views.py` - 5 endpoints (upload, process, delete, reprocess, process_all)
- `queries/views.py` - 2 endpoints (create_conversation, delete_conversation)

**2. Configured Django CSRF for HTMX:**
- Set `CSRF_COOKIE_HTTPONLY = False` (allows JavaScript to read cookie)
- Set `CSRF_COOKIE_SAMESITE = 'Lax'` (balanced security)
- Set `CSRF_COOKIE_SECURE = not DEBUG` (HTTPS in production)

**3. Updated HTMX to send CSRF tokens:**
```javascript
// Get CSRF token from cookie
function getCookie(name) { ... }

// Configure HTMX to send token with all requests
document.body.addEventListener('htmx:configRequest', function(event) {
    const csrfToken = getCookie('csrftoken');
    if (csrfToken) {
        event.detail.headers['X-CSRFToken'] = csrfToken;
    }
});
```

**Files Modified:**
- `templates/base.html` - Updated CSRF token handling
- `config/settings.py` - Added CSRF cookie configuration
- `knowledge/document_views.py` - Removed @csrf_exempt
- `queries/views.py` - Removed @csrf_exempt

**Security Impact:**
- ✅ Full CSRF protection restored
- ✅ Production-ready security posture
- ✅ No functionality lost
- ✅ Prevents cross-site request forgery attacks

**Implementation:**

**New Model: `SystemPrompt` (queries/models.py)**
```python
class SystemPrompt(models.Model):
    prompt_text = models.TextField(default="...")
    is_active = models.BooleanField(default=True)
    updated_by = models.ForeignKey(User, ...)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    def save(self, *args, **kwargs):
        # Ensure only one active prompt
        if self.is_active:
            SystemPrompt.objects.filter(is_active=True).exclude(pk=self.pk).update(is_active=False)
        super().save(*args, **kwargs)
```
